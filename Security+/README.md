# CompTIA Security+ Knowledge Base & Framework Mapping

## Overview & Purpose
This repository serves as a personal study workspace and technical reference guide for information security domains. The content synthesizes core exam objectives, maps security controls to international governance frameworks, and provides structured matrices for quick reference.

## Curriculum Alignment & Acknowledgments
- **Learning Baseline:** The topic sequence and foundational concepts are aligned with the public CompTIA Security+ objectives, utilizing popular community educational resources such as [Professor Messer's Security+ Training](https://www.professormesser.com/) as a primary study foundation.
- **Independent Synthesis:** All explanations, markdown tables, and comparative matrices in this directory are original notes written in my own words to reinforce conceptual understanding.
- **Framework Cross-Referencing:** Concepts are mapped directly to official industry frameworks, including:
  - **NIST SP 800-53 Rev. 5** (Security and Privacy Controls)
  - **ISO/IEC 27001:2022 / ISO/IEC 27002:2022** (Information Security Management)
  - **CIS Controls v8** (Center for Internet Security Critical Controls)

## Repository Structure

The documentation is organized across five core exam domains:

- **`01-General-Security-Concepts/`**  
  Fundamental security principles, control categories and types, change management, and cryptography basics.
- **`02-Threats-Vulnerabilities-Mitigations/`**  
  Threat actors, attack vectors, social engineering, vulnerability types, and mitigation strategies.
- **`03-Security-Architecture/`**  
  Network design, security models, system architecture, data protection, and resilience measures.
- **`04-Security-Operations/`**  
  Incident response, log analysis, threat intelligence, identity/access management, and security monitoring.
- **`05-Security-Program-Management/`**  
  Governance, risk management, compliance standards, vendor security (TPRM), and organizational security policies.
